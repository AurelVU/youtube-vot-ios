# Данные и диагностика

Дополнение не использует собственный сервер аналитики. Для перевода оно обращается к внешним сервисам.

| Получатель | Передаваемые данные |
| --- | --- |
| `api.browser.yandex.ru` | Ссылка и длительность видео, языки и режим озвучки, идентификатор сессии, заголовки протокола. При авторизованном запросе живых голосов — cookie Яндекса. |
| `vot-worker.toil.cc` | Данные неавторизованного запроса при резервном обращении. Cookie аккаунта этому серверу не передаётся. |
| Адреса аудио и субтитров из ответа сервиса | Запрос соответствующего медиафайла. Cookie Яндекса клиентом не добавляется. |
| Страница входа Яндекса в WebKit | Данные, которые пользователь вводит непосредственно в форму входа. |

Внешние сервисы также видят обычные сетевые сведения, например IP-адрес. Их собственные правила обработки данных определяются ими. Дополнение не контролирует хранение данных на их стороне.

Вход сохраняется в стандартном хранилище WebKit внутри приложения. В коде и репозитории нет предзаполненного аккаунта или пользовательских cookie. Общедоступные константы протокола из vot.js не являются индивидуальными ключами пользователя.

Во время работы создаётся локальный `Documents/VOTDiagnostics.json`: время записи, настройки громкости и языков, состояния аудиоплеера, счётчики синхронизации и безопасные коды ошибок. Он содержит только признак наличия авторизации, без значения cookie, пароля или ссылки на медиа. Автоматической отправки файла нет. Перед передачей диагностических материалов проверьте их содержимое. Системные crash reports и запись экрана могут содержать дополнительные данные, не контролируемые этим модулем.

Не прикладывайте к публичным issues cookie, токены, IPA, provisioning profiles, сертификаты, необработанные логи и записи входа в аккаунт.
